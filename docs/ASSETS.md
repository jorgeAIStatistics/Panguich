# Asset register

No photograph, video, or logo file from the restaurant is stored in this repository or shown in the
app. Rights are unknown until the owner confirms them, so every image space is an unmistakable,
labeled placeholder ("Photo placeholder · … · Owner-approved photo goes here").

## Rules

- No stock food photos, no AI-generated dishes, people, crowds, or interiors.
- A photo must show the actual dish as served; alt text describes what is in the picture, without
  portion, ingredient, or health claims beyond what is visible.
- Record for each approved asset: file, subject, photographer/owner, permission date, where used.
